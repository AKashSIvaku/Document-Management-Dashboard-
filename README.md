# Document Management Dashboard

This workspace contains a minimal scaffold for a Document Management Dashboard:

- `frontend` — a Vite + React frontend
- `backend` — a Spring Boot backend (Maven)

Setup:

1. Frontend

```bash
cd frontend
npm install
npm run dev
```

2. Backend

Requirements: JDK 17+, Maven

```bash
cd backend
mvn spring-boot:run
```
